# ipma-open-data-client

Progenitor 0.16.0 generated HTTP client for IPMA `/open-data/` feeds.

Review the [specification](../../specs/open-data.yaml) and
[reference](../../docs/open-data.md). Run generation and verification from the
repository root. `src/generated.rs` is checked in and never edited manually.
See the root README for transport behavior, source-value preservation limits,
examples and evidence. No IPMA requests occur during crate compilation.
